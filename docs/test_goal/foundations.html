Glacier and periwinkle are more characterful but each crowds an existing step token. Bone is the disciplined choice — the interface speaks through the five workflow hues alone.

Five step types

Vertebrae has five step characters in its workflow vocabulary — each owning one hue. The hue appears as a top bar on workflow nodes, a left border on board columns, and a small dot in lists.

5 types · shared with DAG & Board
i
▶ execute
Agent runs

An AI agent executes the step — where work actually happens. The place that costs tokens.

wash step-execute-wash
hue violet · 285°

⊙ eval
Agent judges

An agent scores or checks an output from a previous step. No artifact — just a verdict.

wash step-eval-wash
hue cyan · 200°

⤳ route
Decision point

Conditional fork — the task moves to one of several next steps based on a rule.
