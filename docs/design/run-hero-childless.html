RunHero — a leaf with an active run

The hero's lower zone today is built entirely from children: the ✓ N breakdown, the dot strip, and the "N children" label. A leaf task has no fan-out, so all three collapse to nothing — leaving the status line floating over dead space. The fix: a leaf's only progress is its own run, so re-target that zone from children progress to this run's step trail.

The rule

  • Has children → lower zone = fan-out: dot strip + ✓ / ▶ / ○ breakdown + "N children".
  • Leaf → lower zone = this run's step trail (a Pipeline) + run-scoped stats + "leaf · no children".
  • The status line (icon · state · runtime · at step) is identical in both — only the zone beneath it swaps meaning.
  • Never render an empty hero: an idle leaf shows its defined-but-unrun workflow, dimmed.
