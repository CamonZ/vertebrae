Note from the editor

The synthesis.

The three earlier proposals each picked a corner: Imprint took the paper, Specimen took the scientific labels, Console took the terminal. Each was honest about a single thing it wanted to be.

Hearth is the synthesis. It keeps Console's dark-first discipline — engineers run their tools in dark mode and Vertebrae is no exception — but pulls the colour temperature warm, away from the blue cast of clinical software and toward a workshop lamp at 11pm.

Display moments are set in Newsreader, the same humanist serif from Imprint, so that page titles and section headings read like writing and not like UI. Body copy stays in Geist. Code stays in mono, where it always belongs.

The five step types — execute, eval, route, human review, wait for children — finally get colours that match what they do, not arbitrary buckets. The vocabulary is shown overleaf and used everywhere after.

The five step types

A step in a Vertebrae workflow is one of five kinds. Each owns a hue; the hue is used as a top accent bar on workflow nodes, a left border on board columns, and a small icon in dense lists.

▶ execute
Agent runs

An AI agent executes the step — the place where work actually happens.

step-execute · violet 285°
⊙ eval
Agent evaluates

An agent scores or checks a previous step's output. No new artifact — just a judgement.

step-eval · cyan 200°
⤳ route
Decision point

Conditional fork. The task moves to one of several next steps based on a rule.

step-route · lime 135°
👁 review
Human review

A person must approve or reject. The system waits indefinitely.

step-human · amber 70°
⏸ wait
Wait for children

Paused on subtask completion. Passive — will resume automatically.

step-wait · slate 250°

Three levels of work

Every unit of work lives at one of three levels. Each owns a distinct glyph — used consistently across tree views, board columns, breadcrumbs, and status chips. The hierarchy is always Epic → Ticket → Task.

◈ U+25C8
level 0
Epic

The top-level container. An epic spans multiple tickets and represents a strategic goal or product milestone. Collapsed by default in tree views; always shown with a chevron.

in context · tree view
▼ ◈ Refactor auth system
▷ ◇ Implement JWT service
▷ ◇ Approve PR output
glyph-epic · ◈ L0
◇ U+25C7
level 1
Ticket

A discrete deliverable within an epic. A ticket groups the tasks that together produce a shippable outcome. Runs as a workflow; its step type drives the node bar colour.

in context · tree view
▼ ◈ Refactor auth system
▼ ◇ Implement JWT service
· Create token signing fn
glyph-ticket · ◇ L1
· U+00B7
level 2
Task

The atomic unit of work. A single agent run, a specific acceptance criterion, or a human action. Tasks are always leaves — they never contain children of their own.
