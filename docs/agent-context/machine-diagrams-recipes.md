# Machine-diagram recipes

Read the [authoring guide](machine-diagrams.md) and
[part reference](machine-diagrams-reference.md) first. Each `flow` block here
is a complete spec; check your own with `vtb flow validate`. Timings are
illustrative.


- [Explain a system flow](machine-diagrams/recipes/system.md).
  Load when: writing the system example.
- [Explain code](machine-diagrams/recipes/explain-code.md): principles for an open PR, a merged PR or a part of the system.
  Load when: diagramming real code, reviewing a PR, or explaining how a component works.
- [Explain Before/After with the same inputs](machine-diagrams/recipes/before-after.md).
  Load when: writing the before-after example.
- [Compare several options on one diagram](machine-diagrams/recipes/options.md).
  Load when: weighing design alternatives (option A, option B) against the current machine.
- [Tell a migration in phases](machine-diagrams/recipes/migration.md).
  Load when: showing an architecture moving from today to a target through ordered steps.
- [Add an inline deeper level](machine-diagrams/recipes/drill.md).
  Load when: writing the drill example.
